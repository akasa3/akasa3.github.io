## モチベ

そもそもブログのモチベーションは日々の自分の行動，思考をアーカイブする事にあったけど，如何せん書くのが面倒で全然書いていなかった．が，最近になって下記のモチベがちょっと出たので，この際だから GitHub Pages で書こうと思い至った

- 最近は旅行とか登山の計画を Notion でまとめてたけど，任意のサービスで管理するとサ終したときにサルベージしなければ記録がすべて消えるが，ローカルでも持っておけば，ミスって消すかハードが死なない限り記録が残る
- 登山計画/記録をドキュメントしてちゃんと書いて，ついでに公開したい
- ChatGPT とか その他任意の LLM Agent が出てきて，出来るけど手数的に面倒，みたいなことをやるハードルが下がった．[Gemini CLI](https://github.com/google-gemini/gemini-cli) でローカルファイル検索とかを内容基準でよしなにやってくれる (はずな) ので，過去記事の検索性が向上する，と期待
- 最悪 .md にプログ内容を箇条書きしておけば，あとは LLM が良い感じにしてくれないか? という実験的期待

### ローカル管理 (ついでに公開)

任意サービスへの依存がどう，についてはわざわざ書かないが，記録をローカルで書いてついでに公開するのは登山計画/記録の公開に対するモチベが強い．

登山計画/記録は基本的に[ヤマレコ](https://www.yamareco.com/)に書いている ([プロフィール](https://www.yamareco.com/modules/yamareco/userinfo-635596-prof.html))．が，どうしてももっと細かい計画/記録を残したくなる．道中の話はヤマレコに書けば良いとして，旅程全体の計画や，そもそも計画を立てるプロセスを残しておきたい．あとは，Garmin とかで取った身体ログの分析と，定量/定性での課題把握とか．

本当はスキーもログ取って色々したいが，なかなか意味のあるログをどう取るかのイメージがついていない．

とにかく，こういうのを全部ヤマレコには書けないので，今までは旅程計画だけ Notino に書いていた．ただ，毎回計画立てるたびに細かいアクセスとか宿泊場所とか調べてるので，ちゃんと計画プロセスを文章で残しつつ，たまたま検索してページを見た人の役に立ったり立たなかったりすればよいかと思った．

### LLM Agent

Gemini CLI が出たおかげで，Terminal から色々出来るようになったのが個人的に嬉しい．実は以前から同様のことが可能な何かはあったのかもしれないが，全然この辺りをキャッチアップできていない．[Warp](https://www.warp.dev/)を使っているので，Tarminal に Agent が付いてるの地味に便利とは思っていた．

Gemini (Gemini 2.5 Pro) の出力は稀に怪しい感じはするけど，精度向上は時間が解決するだろうからそこまで気にしていない．いろんな MCP サーバと繋いだり，個人で拡張機能作ってカスタム出来るのが個人的に嬉しい．Google の個人アカウントを持っていれば [60 requests/min, 1000 requests/day を無料で使える](https://blog.google/technology/developers/introducing-gemini-cli-open-source-ai-agent/#:~:text=That%20free%20license%20gets%20you%20access%20to%20Gemini%202.5%20Pro%20and%20its%20massive%201%20million%20token%20context%20window.%20To%20ensure%20you%20rarely%2C%20if%20ever%2C%20hit%20a%20limit%20during%20this%20preview%2C%20we%20offer%20the%20industry%E2%80%99s%20largest%20allowance%3A%2060%20model%20requests%20per%20minute%20and%201%2C000%20requests%20per%20day%20at%20no%20charge.)のも良い (2025/07/06 (Sun) 時点)．

Terminal 上から使える Agent を使えば，任意の内容が書かれている記事の検索を自然言語で行えて楽になるんじゃないかと思っている．

あとは，もう少しファイルが溜まったら，ブログ内容を箇条書きした .md file を渡せば，代わりに文体を倣ったブログを勝手に書いてくれるのでは? と勝手に思っている．箇条書きからニュアンスまで汲み取るのは難しそうだったり，そもそも意味あるのか? とは思うが，書きたいが時間がない/どうしても面倒くさい時に重宝しそう．

## 何を書くか

上述したとおりではあるが，登山計画/記録だったり，何か日常のこと，まれに技術的なことを書き溜めていきたい．ごく稀にしか更新しないかもしれないが，そのうち Gemini が毎週記事を書いているかもしれない．．
